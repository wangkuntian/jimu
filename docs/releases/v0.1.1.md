## 亮点

依赖与 CI 全面升级，构建产物统一为 golang:1.27-alpine，安全扫描（Trivy/govulncheck）保持零高危告警。

## 新增

- 本版无用户可见新功能，属于依赖与工程化稳固版本

- 构建镜像升级 golang:1.26 → 1.27-alpine（Dockerfile）

- GitHub Actions 升级：checkout@v7、setup-go@v7、golangci-lint-action v9、softprops/action-gh-release v3 等
- CI 流水线并行化、优化触发范围并移除失效 build job
- 发布流程以 `docs/releases/<version>.md` 作为 Release body 来源

## 修复

- Trivy 安全扫描升级至 v0.36.0，修复 x/image CVE-2026-46602 及 x/mod 高危告警
- 镜像 smoke test 容器可达性
- CI 修复：docker-compose healthcheck、mariadb 12.1.2-noble 恢复、golangci-lint goinstall 安装、测试库注册雪花 hook
- notification 测试 data race（mockConn 加 mutex）

- `make release-check`（fmt-check + vet + test + govulncheck）通过
- 全部 PR 合并前 CI 8 项检查全绿
- Trivy 镜像扫描零 CRITICAL/HIGH
