# v0.1.0

## 亮点

首个正式版本。Go 通用后端框架稳定底座 + 可组合模块 + 标准适配器 + 脚手架生成，覆盖开发→部署→运维→观测→CI 全链路闭环。

## 新增

- **模块化架构** — Clean Architecture 分层，业务逻辑依赖接口不依赖实现；`contract.Module` 统一注册
- **统一认证** — typed JWT + Redis refresh session + Casbin RBAC v3；API Key 认证；自助密码重置（邮箱验证码，防枚举，重置后强制登出全部会话）
- **敏感字段加密** — AES-256-GCM 字段级加密 + HMAC-SHA256 盲索引（email/phone）
- **OAuth 登录** — Google/GitHub/微信第三方登录
- **多队列 + 可靠传递** — Redis/Kafka/RabbitMQ 统一接口，三者均 at-least-once；消费幂等去重；失败指数退避延迟重投；耗尽重试入死信表（管理 API 可查询与标记解决）；Outbox 保证事件发布与 DB 事务一致
- **上传安全** — 大小限制 + magic-byte 嗅探覆盖可伪造 Content-Type + MIME 白名单；可选 ClamAV 病毒扫描（stdlib INSTREAM 协议，落库前同步扫描，fail-closed）
- **可观测性** — OpenTelemetry 分布式追踪（HTTP/Gorm/Redis 全链路）+ Prometheus 指标（DB/HTTP/队列/Outbox/熔断/调度）+ Zap 结构化日志 + 访问日志注入 trace_id
- **gRPC 双栈** — 与 HTTP 并存，内置健康检查 + 反射
- **文件存储** — 本地/S3/OSS/MinIO 统一接口
- **通知系统** — 邮件/短信(阿里云)/WebSocket/Webhook，Webhook 载荷 HMAC-SHA256 签名
- **统一出站 HTTP client** — timeout + retry/backoff + 熔断 + 按 host 限流 + traceparent 注入
- **HTTP 安全边界** — 请求体大小/超时/可信代理/CORS/安全头；CSRF 防护；API 签名验证
- **限流** — 全局令牌桶 + 登录/注册固定窗口 + 用户维度滑动窗口
- **定时任务** — robfig/cron，MySQL 持久化 + 多实例分布式锁协调
- **审计日志 / 缓存 / 分布式锁 / Feature Flag / 数据导入导出**
- **管理 API** — 系统状态、在线用户、强制下线、错误码文档、特性开关、任务、死信
- **脚手架** — Cobra CLI 一键生成完整模块骨架
- **部署与 CI/CD** — Dockerfile + docker-compose + K8s manifests + Helm chart；GitHub Actions + Dependabot；govulncheck + Trivy + SBOM + 镜像 smoke test；golangci-lint + pre-commit；覆盖率门禁 ≥ 70%

## 变更

- 配置系统标准化，统一枚举值启动校验
- Casbin 升级至 v3，RBAC 模型适配
- Makefile 命令命名统一（docker / compose 分组）
- 移除多租户抽象，明确单租户 RBAC 定位

## 修复

- Swagger UI 不可访问问题
- Viper 不再加载 `.env`，避免与 docker-compose `env_file` 冲突
- 移除硬编码管理员密码，改为环境变量注入

## 说明

- 首版本，API 视为稳定基线；后续按 SemVer 演进
- `COMPOSE_ENV` 环境变量在 `make release-check` 中的集成尚未实现（CLAUDE.md 规范提及 `make release-check COMPOSE_ENV=.env.example`，当前 release-check target 为 go 层门禁，不消费该变量）；compose 集成验证作为后续项
- Kafka at-least-once 消费端须幂等（框架已对已成功/死信任务去重，业务 handler 副作用仍需自行幂等）
- ClamAV 扫描为同步阻塞，大文件 + 慢 clamd 增加上传延迟（默认 10s timeout 兜底）
- 数据库支持 MySQL/MariaDB/PostgreSQL，迁移文件按 driver 隔离
