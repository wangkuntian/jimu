# v0.7.0

> 状态：已发布（2026-11-03）

## 亮点

- 新增独立 Release CLI：安装后可在 Jimu checkout 之外生成、检查、升级和扩展项目。
- template bundle 内嵌到单个 CLI，Release 同时提供 `template-bundle.json` 和 SHA-256 checksums。
- 新增无 checkout 的 clean-room 发布门禁，覆盖 `basic-api` 和 `auth-api` 的生成与运行。
- README 首屏重写为产品入口，能力、配置、运维、升级、比较和生产检查拆分到独立文档。

## 新增

- Release CLI：`jimu` 支持 `new`、`check`、`upgrade`、`capability add` 和 `version`，不包含 server 运维命令。
- 单文件分发：template bundle 内嵌到 CLI，生成项目不再要求 Jimu checkout。
- 版本契约：Release tag 同时绑定 CLI 和 template bundle；`jimu version` 显示 CLI、template bundle、contract 和 commit。
- Release 资产：四个平台的 CLI、`template-bundle.json` 和 SHA-256 checksums。
