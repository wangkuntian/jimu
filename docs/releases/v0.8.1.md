# v0.8.1

> 状态：发布候选（2026-11-05）

## 亮点

- 确认 `v0.8.1`–`v1.0` 六个月路线：路线 A 维护 + 8 周实验性 full-stack demo。
- 明确 profile 是内部构建形态；退役 `enterprise`/`machine`/`saas`，冻结 `minimal`，保留 `full`。

## 变更

- 更新 `docs/REQUIREMENTS.md`：六个月需求列表、容量、里程碑、非目标和当前风险。
- 新增 ADR 0005（solo-maintainer 合并规则）、ADR 0006（full-stack demo 边界）、ADR 0007（profile 是内部构建形态）。
- 术语表补充 profile、frozen/retired profile、full-stack demo 和 full-stack preview。
- 退役 `enterprise`、`machine`、`saas`：删除 assembly、registry 条目、路由 golden、检查脚本和测试；`full` 保留，`minimal` 冻结。
- 更新 README、形态设计文档、模板契约、agent skill 和 compose 报告，移除退役 profile 的当前事实。
