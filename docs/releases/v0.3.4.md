# v0.3.4

## 亮点

- 审查并收敛 capability 边界：配置、清理作业与数据所有权由对应 capability 负责。

## 变更

- 删除无消费者的 `feature` capability 与独立 `retention` capability；保留通用 `dbpurge`，审计、队列、Outbox、导入记录和可信设备清理分别归属 `audit`、`queue`、`outbox`、`dataops` 与 `mfa`。
- 将 WebAuthn 配置归属 `passkey`，开通式注册配置归属 `tenant`，可信设备配置归属 `mfa`；`auth` 保留会话与认证配置。
- 移除旧顶层 `retention` 配置段和生成器特判；脚手架能力集合继续从 catalog、Ungated 声明和 profile 清单派生。
- 用基于当前实现的无日期详细设计文档替换旧提案稿，补充设计索引、流程图、决策和实现映射，并将 README、AGENTS 和生成报告链接切换到新的设计事实入口。
