**Goal:** 让「代码之外的东西」也随能力/形态可组合：能力用 `Descriptor.Assets` 声明自己的非代码资产并被门禁校验（唯一归属、无未声明资产），本仓的部署与测试路径按当前形态条件化（APIdocs 生成/校验、契约测试、CLI 命令、迁移与种子），且 `full` 行为零变化。

**Architecture:** 资产归属用「能力声明 + 内核具名资产组 + 最长前缀匹配」的单一派生（共享包 `tools/internal/profileassets`，被门禁与新 CLI `tools/profileassets` 共用，沿用 `tools/internal/{heavydeps,profileoverlay}` 的先例）。本仓条件化沿用 P2.5b 的形态机制（唯一入口 + `-overlay`），不引入第二套开关。**渲染**（按能力裁剪 `values.yaml`/`configs/app.yaml`、生成项目里「未选中资产不出现」）明确留给 P2.7。

**Tech Stack:** Go 1.26 · `golang.org/x/tools/go/packages`（既有）· cobra（仅 `cmd/cli` 与能力的 `cli` 子包）· testify

**Spec:** 设计 §3.8 / §8 / §9 / §11；本仓 `configs/*.yaml` 逐字节不变、catalog 仍 18 项、层②不减小 `go.mod`。

## 裁定（brainstorming 已确认，执行前必读）

1. **执行流程**：SDD 逐任务（新子代理实现 + 控制者审查并自跑门禁）→ 审查通过后控制者提交（只 add 本任务文件）→ 整分支审查 → 推送并开 PR 到 `release/v0.3.0`。**禁止未授权提交**。
2. **P2.6 边界**：资产归属 + 本仓部署/测试条件化 + **profile 驱动的迁移裁剪**；**不实现渲染**（`values.yaml`/`configs/app.yaml` 按能力裁剪归 P2.7）。
3. **资产归属模型**：能力用 `contract.Descriptor.Assets`（仓库相对路径：目录前缀或具体文件）声明；内核资产用**具名资产组**（`ops` / `observability`）在共享派生包里声明；归属判定 = **最长前缀匹配**（具体文件赢过目录），每个文件恰有一个**有效**所有者。**不新增 `obs` 能力**（catalog 保持 18 项）——设计 §3.8 里「随 `obs` 能力携带」的意图改由 `observability` 资产组表达。
4. **e2e 深度**：彻底重基为「按当前形态装配」，但**只换模块清单**（`assembly.WireFor`），e2e 保留其现有的路由装配三步与 httptest 打法；**不改 `app.Bootstrap`**（`Bootstrap` 内部自建 router 且不暴露，`*Application` 只有 `Run` 启动监听——`internal/app/application.go:11`、`internal/assembly/assembly.go:124/132`）。抽出 `app.BuildRouter` 让两者共用列为**可留后续**。
5. **迁移/种子裁剪的取数口径（关键）**：`cmd/cli` 用**从 `catalog.All()` 过滤出当前形态声明的能力名**，**不能**用 `Assembly().Capabilities` 的顺序——`resolveCapabilities`（`internal/assembly/assembly.go:144`）返回的是**装配顺序**，而迁移有真实依赖（`tenant` 的迁移 ALTER `users`/`roles`，必须排在 `user`/`access` 之后）。过滤 `catalog.All()` 既保拓扑序，又使 `full` 与今天**逐值相同**（full 声明集覆盖全部 18 项 catalog）。已核实 7 个非 catalog（Ungated）条目（`apidocs`/`storage`/`notification`/`retention`/`ws`/`grpc`/`encryption`）**都没有** `Permissions`/`Migrations`，故该过滤不丢任何迁移或权限点。
6. **CLI 命令归属**：能力在**自己的包内**提供 `internal/capabilities/<name>/cli` 子包并导出 `Commands() []*cobra.Command`；`cmd/cli` 显式 import 并注册（与 P2.5「驱动显式 import + 注册」同构）。`internal/contract` **不**引入 cobra。本仓 `cmd/cli` 保留全部命令（它是开发工具）；生成项目的 CLI 裁剪归 P2.7。
7. **A/B/C（交接文件 §4）已由 P2.5b 覆盖**：`PROFILE=` 已贯穿 Makefile/Dockerfile/compose，形态在本仓构建/部署路径上可选。本阶段不再选 A/B/C，只在文档里记录该结论。
8. **沿用硬约束**：`configs/*.yaml` 逐字节不变；catalog 仍 18 项；`go.mod` 不减小；能力间只经 `contract`；`internal/kernel/**` 不 import `internal/capabilities/**`；`internal/app` 不 import `catalog`/能力根包/`assembly`（三个 domain 叶子包是既已记录的偏差）。

```go
// tools/internal/profileassets/profileassets.go
// Package profileassets 派生「谁拥有哪些非代码资产」，供门禁（tools/checkcapabilities）
// 与查询工具（tools/profileassets）共用，避免两处漂移（先例：tools/internal/heavydeps）。
//
// 归属规则：能力用 Descriptor.Assets 声明，内核运维/观测资产用下面的具名资产组声明；
// 同一路径被多处声明时，**最长前缀获胜**（具体文件赢过目录），因此每个文件恰有一个有效所有者。
package profileassets

// coreGroups 内核资产组：不属于任何能力，**全形态携带**（生成项目是否携带由
// P2.7 的生成器按需要取舍；本阶段只表达归属）。
var coreGroups = map[string][]string{
	"ops":           {"deploy/k8s", "deploy/helm", "deploy/backup"},
	"observability": {"deploy/openobserve", "deploy/otel-collector.yaml",
		"deploy/k8s/openobserve.yaml", "deploy/k8s/otel-collector.yaml",
		"deploy/helm/templates/openobserve.yaml", "deploy/helm/templates/otel-collector.yaml"},
}

// AssetRoots 是门禁扫描的资产根（不纳入 configs/：本仓逐字节不变，渲染归 P2.7）。
func AssetRoots() []string { return []string{"deploy", "docs/openapi"} }

// CoreGroups 返回内核资产组（副本）。
func CoreGroups() map[string][]string

// Owner 用最长前缀匹配返回路径的有效所有者：能力形如 "cap:<name>"，内核组形如 "group:<name>"。
// 不在任何声明前缀下的路径返回 ok=false。
func Owner(path string) (string, bool)

// Ownership 遍历资产根下所有文件（跳过以 "." 开头的文件/目录），返回 path → owner。
func Ownership(root string) (map[string]string, error)

// ForProfile 返回该形态的资产路径（能力 Assets 并集 + 内核资产组），去重排序。
func ForProfile(profile string) ([]string, error)
```

  - `Owner`/`Ownership` 的具体实现：把 `cap:<name> → Descriptor.Assets`（来自 `catalog.All()` 与 `internal/profiles/registry` 的形态清单；为覆盖非 catalog 的 `apidocs`，遍历 `registry.All()` 的全部形态清单并集）与 `group:<name> → coreGroups` 合并成前缀表；匹配时要求「路径 == 前缀」或「路径以 `前缀 + "/"` 开头」；长度更长者获胜。
  - `ForProfile` 用 `registry.Lookup(profile)` 取该形态的能力名，从上面的前缀表取并集 + 全部内核组。
