> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把层②的入口从「5 个 `profiles/<name>/main.go`」收敛为**唯一入口 `cmd/server`**，并把「当前形态」变成一个**构建期输入参数**（`PROFILE=minimal make build-server`、`--build-arg PROFILE=minimal`），且**不放弃编译期裁剪** —— 未选中的形态与驱动不进 import 图（`full` 闭包 118 个重型依赖包、四个轻形态 0 的数字必须逐值不变）。

**Architecture:** 新增选点包 `internal/profiles/active`（提交态默认 `full`，只 import 一个形态包），`cmd/server/main.go` 只 import 它；切换形态靠 Go 工具链的 `-overlay`：`tools/profileoverlay <profile>` 生成「只选该形态」的 `active.go` 替代版本与 overlay JSON（写进 gitignore 的 `.overlay/`），构建命令带 `-overlay=` 即得该形态产物，**磁盘上的仓库文件一个字节都不动**（`go build`/`go test`/`go vet`/`go list` 均支持）。形态清单的唯一来源收口到 `internal/profiles/registry`（只被 `tools/*` 引用，绝不进 `cmd/server` 的图）。

**Tech Stack:** Go 1.26（`-overlay` 自 1.16 起）· `golang.org/x/tools/go/packages`（`packages.Config.Overlay` 内存叠加，`tools/` 既有依赖）· 原生 JSON（生成 overlay 配置）· testify

**Spec:** 设计 §6.3 / §9 / §11；`configs/*.yaml` 逐字节不变、catalog 仍 18 项、层②不减小 `go.mod`。

## 裁定（brainstorming 已确认，执行前必读）

1. **唯一入口 = `cmd/server/main.go`**（swagger 注解、`-X main.version`、Dockerfile/CI/`swag -g` 都指向它，全部不用挪）。**选点 = `internal/profiles/active/assembly.go`**（`package active`，只 import 一个形态包）。文件按内容命名，不用 `active/active.go` 那种重复写法。
2. **切换机制 = overlay，不是生成式、不是 build tag**：
   - 生成式（改 `active.go` → 构建 → 还原）会脏树、不可并行、构建崩溃会把仓库留在别的形态；
   - build tag 会让「不带 tag 的默认构建/`go test ./...`」编译出一棵**被裁掉驱动的树**，默认语义退化，且 P2.4 已裁定不引入新 tag 空间；
   - overlay 每次命令自洽、不脏树、可并行，且 `go list -overlay -deps` 让 golden 闭包门禁仍能问出「某形态的闭包是什么」。
3. **默认值语义（硬约定）**：提交态恒为 `full` → `go build ./cmd/server`、`go test ./...`、IDE、`make swagger` 默认都是 full（一个完整可跑的程序）；其余形态一律显式 `PROFILE=<name>`。
4. **删除 5 个 `profiles/<name>/main.go`**（列在最后一个代码任务，保证每步全绿）；开发者用法变为 `PROFILE=<name> make build-server`，产物 `bin/jimu-server-<name>`（`full` 仍是 `bin/jimu-server`，保持兼容）。这是**开发者可见的行为变更**，写进 release note。
5. **形态清单唯一来源 = `internal/profiles/registry`**：`Names()`/`All()`/`Lookup()` 汇总 5 个形态包，只被 `tools/*`（`profileoverlay -list`、`checkcapabilities`、`composereport`）引用；`scripts/check_profiles.sh` 的形态名从 `go run ./tools/profileoverlay -list` 取。顺带收口 T6 审查记的「形态清单散落多处」deferred minor。
6. **驱动参数化只做形态级**：驱动集合仍由各形态 `drivers.go` 的 blank import 决定（P2.5 的 `Descriptor.Drivers`/`Capability.Drivers` 与五条门禁断言原样有效）。`PROFILE=enterprise DRIVERS=local` 这类形态内再选驱动需要第二份真源 + 生成 `drivers.go` + 门禁改读它，**留后续阶段**，本阶段只在文档写明边界。
7. **不动**：`cmd/server` 的 swagger 注解与 `swag -g`、`cmd/cli`（仍用全量清单做 migrate/seed）、`configs/*.yaml`、catalog（18 项）、门禁入口名（仍 `make check-capabilities`）、`make ci`/`release-check` 的成员（门禁接入 CI 属 P2.8）。
8. **沿用硬约束**：`configs/*.yaml` 逐字节不变；catalog 仍 18 项；层②不减小 `go.mod`；能力间只经 `contract`；`internal/kernel/**` 不 import `internal/capabilities/**`；`internal/app` 不 import `catalog`/能力根包/`assembly`；**禁止自动提交**（AGENTS.md 最高优先级，每个 Task 的 commit 仅在用户明确指令后执行）。

## Global Constraints

- **每步全绿**：`gofmt -l .`（无输出）、`go build ./...`、`go vet ./...`、`golangci-lint run ./...`（CI 固定 v2.7.2，走 `make lint`）、`make check-log-usage`、`go test ./... -count=1`、`make check-capabilities`、`make profiles-check`、`git diff --stat configs/` 为空。
- **编译面结果不该变（本阶段的核心验收）**：`make compose-report` 生成的 `docs/profiles/compose-report.md` 里，**路由/迁移/表/重型依赖列必须逐值不变**（`full` 118 个重型依赖包，四个轻形态 0）；`**本仓 Go 文件` 与「本仓代码行」两列**会按入口文件的差异变化，这是可解释且预期的：闭包根从 `./profiles/<name>`（1 个入口文件）变成 `./cmd/server`（`main.go` 32 行 + `internal/profiles/active/assembly.go` 14 行 = 2 个文件），因此 **文件 +1**、**代码行 = 新入口两文件行数 − 旧入口文件行数**（实测：新 `cmd/server/main.go` 32 行 + `internal/profiles/active/assembly.go` 14 行 = 46；旧 `profiles/full/main.go` 21 行、其余 16 行 → **`full` +25、其余四形态 +30**）；二进制差异来自入口文件本身（实测 `full`/`minimal` +16 KB 量级、`saas`/`enterprise` −80 B、`machine` 0）。执行 T3 时要把实测差值记进报告，与上述口径核对；对不上就是机制出错，要停下来查。
- **所有构建入口统一带 overlay，且必须 fail-fast**：Makefile、Dockerfile、compose、`check_profiles.sh`、`composereport`、`checkcapabilities`。**注意**：`go build -overlay=` 空值会被当作「无 overlay」而 exit 0（实测），因此**不能**把命令替换直接写进 `-overlay=$$(...)` —— 形态名非法/工具失败时会静默产出 full 产物。写法必须是「先赋给 shell 变量再 `&&` 构建」（Makefile 与 Dockerfile 各一处），使非法形态名 exit 2 且无产物；门禁与报告口径只作第二层兜底。
- **overlay 生成物一律 gitignored**：`.overlay/` 进 `.gitignore`；任何 `PROFILE=` 构建后 `git status --short` 必须为空。
- **形态名白名单**：只认 `full`/`minimal`/`saas`/`enterprise`/`machine`（来自 registry）；非法名要报错并列出可用形态。
- 分支从 `release/v0.3.0`（`bb26d83`）切出：`feature/p2.5b-unified-entry`；PR 目标 `release/v0.3.0`（squash merge）。

```go
// Package registry 汇总全部形态清单，作为「形态有哪些」的唯一来源，供 tools/* 使用。
//
// 它 import 全部 5 个形态包，因此**绝不能被 cmd/server 或 internal/profiles/active 引用**

package registry

import (
	"fmt"
	"strings"

	"jimu/internal/assembly"
	"jimu/internal/profiles/enterprise"
	"jimu/internal/profiles/full"
	"jimu/internal/profiles/machine"
	"jimu/internal/profiles/minimal"
	"jimu/internal/profiles/saas"
)

// names 固定顺序：报告行序、门禁与脚本的遍历顺序都依赖它。
var names = []string{"full", "minimal", "saas", "enterprise", "machine"}

// Names 返回全部形态名（按固定顺序）。
func Names() []string { return append([]string(nil), names...) }

// All 返回形态名 → 装配清单。
func All() map[string]assembly.Assembly {
	return map[string]assembly.Assembly{
		"full":       full.Assembly(),
		"minimal":    minimal.Assembly(),
		"saas":       saas.Assembly(),
		"enterprise": enterprise.Assembly(),
		"machine":    machine.Assembly(),
	}
}

// Lookup 按名取装配清单；未知形态返回错误并列出可用形态。
func Lookup(name string) (assembly.Assembly, error) {
	if a, ok := All()[name]; ok {
		return a, nil
	}
	return assembly.Assembly{}, fmt.Errorf("unknown profile %q (available: %s)", name, strings.Join(names, ", "))
}
```

```go
// Command profileoverlay 为指定形态生成 overlay 配置：把
// internal/profiles/active/assembly.go 在**本次构建**中替换为「只选该形态」的版本，
// 不改动工作区里的任何文件。
//
//	go run ./tools/profileoverlay <profile>   # 写 .overlay/{active.go,overlay.json}，打印 JSON 路径
//	go run ./tools/profileoverlay -list       # 打印全部形态名（每行一个）
//
// 用法示例：
//
//	go build -overlay=$(go run ./tools/profileoverlay minimal) -o bin/server ./cmd/server
//	go test -overlay=$(go run ./tools/profileoverlay minimal) ./internal/profiles/...
package main

import (
	"encoding/json"
	"fmt"
	"os"
	"path/filepath"
	"strings"

	"jimu/internal/profiles/registry"
)

// overlayDir 是生成物目录（gitignored）。
const overlayDir = ".overlay"

// activePath 是被替换的选点文件（相对仓库根）。
var activePath = filepath.Join("internal", "profiles", "active", "assembly.go")

func main() {
	if len(os.Args) == 2 && os.Args[1] == "-list" {
		fmt.Println(strings.Join(registry.Names(), "\n"))
		return
	}
	if len(os.Args) != 2 {
		fail(fmt.Errorf("用法：profileoverlay <profile> | -list"))
	}
	root, err := repoRoot()
	if err != nil {
		fail(err)
	}
	jsonPath, content, err := overlayConfig(root, os.Args[1])
	if err != nil {
		fail(err)
	}
	src, err := activeSource(os.Args[1])
	if err != nil {
		fail(err)
	}
	if err := os.WriteFile(filepath.Join(root, overlayDir, "active.go"), []byte(src), 0o644); err != nil {
		fail(err)
	}
	if err := os.WriteFile(jsonPath, content, 0o644); err != nil {
		fail(err)
	}
	fmt.Println(jsonPath)
}

func fail(err error) { fmt.Fprintln(os.Stderr, "❌ profileoverlay:", err); os.Exit(1) }

// activeSource 返回选点文件的替代内容；形态名经 registry 白名单校验。
func activeSource(profile string) (string, error) {
	if _, err := registry.Lookup(profile); err != nil {
		return "", err
	}
	return fmt.Sprintf(`// Code generated by tools/profileoverlay; DO NOT EDIT.
// 本文件是 overlay 替换版：把 internal/profiles/active 的选点指向 %s 形态。
package active

import (
	"jimu/internal/assembly"
	"jimu/internal/profiles/%s"
)

// Assembly 返回本次构建选中的形态。
func Assembly() assembly.Assembly { return %s.Assembly() }
`, profile, profile, profile), nil
}

// overlayConfig 返回 overlay JSON 的路径与其内容（键值都必须是绝对路径）。
func overlayConfig(root, profile string) (string, []byte, error) {
	if _, err := registry.Lookup(profile); err != nil {
		return "", nil, err
	}
	cfg := struct {
		Replace map[string]string `json:"Replace"`
	}{Replace: map[string]string{
		filepath.Join(root, activePath): filepath.Join(root, overlayDir, "active.go"),
	}}
	content, err := json.MarshalIndent(cfg, "", "  ")
	if err != nil {
		return "", nil, err
	}
	if err := os.MkdirAll(filepath.Join(root, overlayDir), 0o755); err != nil {
		return "", nil, err
	}
	return filepath.Join(root, overlayDir, "overlay.json"), append(content, '\n'), nil
}

// repoRoot 从当前工作目录向上找 go.mod（make/Docker 都从仓库根调用，此处兼容子目录调用）。
func repoRoot() (string, error) {
	dir, err := os.Getwd()
	if err != nil {
		return "", err
	}
	for {
		if _, err := os.Stat(filepath.Join(dir, "go.mod")); err == nil {
			return dir, nil
		}
		parent := filepath.Dir(dir)
		if parent == dir {
			return "", fmt.Errorf("找不到 go.mod（从 %s 向上）", dir)
		}
		dir = parent
	}
}
```
